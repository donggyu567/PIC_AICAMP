# PIC: 실시간 보이스피싱 위험 분석·경고

## 현재 프로젝트 방향

PIC는 개인 휴대폰 통화 상황에서 보이스피싱 위험을 분석하고 앱에 결과를 보여 주는 시연 프로젝트다. **시연 앱의 음성 입력은 마이크**다. 휴대폰의 실제 통화 음성을 앱이 직접 가져오는 기능이나 통신사 제휴가 완료되었다고 가정하지 않는다.

2026-10-23에 정한 방향은 인식 성능이 낮았던 기기 내 ONNX STT를 **ElevenLabs 실시간 STT API**로 교체하는 것이다. 음성은 앱에서 자체 서버를 거쳐 ElevenLabs로 보내고, 인식된 텍스트는 앱으로 돌려받아 **기기에서 개인정보를 마스킹**한다. 마스킹된 텍스트를 서버의 후속 분석 입력으로 보낸다.

이 방향은 이전 [3차 멘토링 후 논의 문서](https://docs.google.com/document/d/1QjDP5g1heAxdiuELIFnRhXsd6y3vRl9sP4rQXAZ9pos/edit?tab=t.0#heading=h.nq14f2gpb8qd)의 STT 후보 검토와 통화 음성 연동 가정보다 최신 결정이다. 이후 작업은 아래 흐름을 기준으로 한다.

## 목표 파이프라인

```text
앱: 마이크 음성 수집
  → 서버: 음성을 ElevenLabs 실시간 STT API에 전달
  → 서버: 인식된 텍스트를 앱에 반환
  → 앱: 개인정보 마스킹
  → 앱: 마스킹된 텍스트를 서버에 전송
  → 서버: OpenAI 한 번 호출로 발화 보정 + 통화 문맥 위험 판단
  → 서버: 반환된 보정 문장으로 기존 위험 탐지 AI 분석 및 위험도 계산
  → 서버: 분석 결과·경고/근거 생성 후 앱에 반환
  → 앱: 결과 화면 출력
```

STT에 보내는 **음성은 마스킹 전에 기기 밖으로 나간다.** ElevenLabs가 인식한 원문 텍스트도 앱에 돌아온 뒤 마스킹된다. 따라서 “음성과 STT가 모두 온디바이스에서 처리된다”거나 “마스킹 전 정보는 외부로 전송되지 않는다”고 설명하지 않는다. 기기 내에서 수행하는 단계는 목표 흐름의 **텍스트 마스킹**이다. 음성·원문 텍스트의 전송, 보관, 삭제 및 동의 방식은 구현과 시연 설명에서 명확히 정해야 한다.

## 서버 운영

AWS Lightsail에서 HTTPS API와 WebSocket을 운영한다. 배포 범위, 환경 설정, 검증 결과는 [서버 README](server/README.md)를 확인한다.

## 현재 구성과 검증 상태

- [Android 앱](android/README.md)은 마이크 입력과 ElevenLabs 중계, 기기 내 마스킹, 분석 결과·기록, 신고 자료 복사를 연결한다. 분석 대기 화면은 기기 기록에서 주의 이상인 통화를 센다.
- [서버](server/README.md)는 STT 중계, 위험 분석·통화 종료, LLM 통화 요약·피해 경위 초안 API를 제공한다. 기존 backend·models·risk_speech_ai 코드를 사용한다. 요청과 응답은 [앱·서버 계약](server/document/APP_SERVER_CONTRACT.md)을 따른다.
- AWS Lightsail에서 통화 요약과 피해 경위 API가 배포되어 있다. 가상의 마스킹 통화로 두 LLM 응답을 확인했다. 최신 통합본의 휴대폰 신고 흐름과 탐지 품질은 별도 검증 대상이다.

## 다른 채팅과 작업의 기준

기획, 앱·서버 구현, 테스트, 발표 자료는 위 **마이크 → 서버 경유 ElevenLabs STT → 앱 내 마스킹 → 서버 OpenAI 보정·문맥 판단 통합 호출 → 보정 문장으로 AI 계산 → 앱 결과 화면** 순서를 따른다. 이전 ONNX STT 경로, 은행 창구 시나리오, 통화 음성 직접 연동 가정을 현재 목표로 이어 쓰지 않는다. 기능 요구사항은 [기능 명세서](<PIC 프로젝트_기능명세서_2026-10-28.md>), 새 서버의 구현 순서·진행 상황·연결 계약은 [새 서버 문서](server/README.md)를 확인한다. [기존 backend 문서](backend/document/README.md)는 재사용할 기능과 기존 동작의 참고 자료이며 새 서버 연결 완료를 의미하지 않는다.
