Bootstrap은 등록 scenario_family_id 단위 2,000회, seed20261110으로 동결했다. 이 TEST에서는 가족과 대화 단위가 일대일이다. 유형별 양성 가족은 4개에 불과하며 의미적 독립성을 검증한 수가 아니다. 양성 지원이 사라지는 재표집은 해당 출력에서 제외한다. 유형별 F1 구간은 test_results.json에 있다.

개인정보 요구 성능과 미탐/오탐은 위 per-seed personal_information 행의 실제 TP/FP/FN, P/R/F1/AP로 분석한다. AP와 0.5 판정 F1은 서로 다른 지표다. 낮은 F1을 보고 임계값을 내리거나 seed를 교체하지 않았다. 개별 TEST 본문·정답·오류 발화 목록은 동결된 반출 정책상 저장하지 않았으므로 발화 사례를 추정하거나 새로 만들어 제시하지 않는다.

개인정보 요구: seed42는 TP12/FP74/FN0으로 오탐이 많고, seed43은 TP2/FP0/FN10, seed44는 TP3/FP2/FN9로 미탐이 많다. seed43은 AP 0.9936에도 양성 확률 평균이 0.4746으로 임계값 0.5 아래다. 유형 오탐은 다른 위험 유형도 포함한 해당 유형 음성에서 계산하며 정상 대화 이진 오탐과 구분한다. 점수 순위와 고정 임계값 판정의 차이가 관측되지만 라벨 오류나 의미적 혼동을 원인으로 확정하지 않는다.

정보탐색은 세 seed 모두 TP0/FN12로 실패했다. 비밀유지 F1은 0.8148/0.6857/0.1538로 불안정하다. 서버 기본 seed42의 정상 대화 이진 오탐은 3/8=37.5%이며 세 seed 평균 25%와 구분해야 한다. 합성 소표본 결과로 실제 운영 적합성을 입증하지 못한다.

v1은 동일 tokenizer 내용/probe와 문장쌍 계약으로 CPU 로딩/추론을 검증했다. 현재 발화와 이전 최대 5발화, 512토큰, history 전체 발화 제거 규칙은 동일하다. 역사적 v1 학습 데이터·전사/튜닝 과정이 v2와 동일한 것은 아니며, 추가 ASR·마스킹·전사 정규화 계층의 동등성까지 검증한 것은 아니다. 동일 TEST 입력에서의 비교 결과로 한정한다.

B_ratio 후보와 서버 기본 seed42는 TEST 이전에 고정한 그대로다. TEST에서 v1 또는 다른 arm/seed가 더 좋게 나오더라도 이번 결과로 바꾸지 않는다. 운영 적용은 합성 소표본·미검수 라벨·개인정보 탐지 취약성·분할 의미 독립성 미확인·실제 통화/ASR 분포 차이 때문에 아직 승인된 상태가 아니다.
