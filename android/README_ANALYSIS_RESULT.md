# 분석 결과 디테일 화면

Android는 `POST /api/v1/conversations/end`가 성공하면 최종 점수와 종료 시각을 표시하고 기기 기록을 저장한다. 점수가 0점인 통화도 기존 기록 흐름으로 저장한다.

| 화면 항목 | 표시 방식 |
| --- | --- |
| 상단 제목 | 서버의 `title`을 기록 카드와 상세 화면에 공통으로 표시한다. 값이 없으면 ‘최종 분석 결과’를 표시한다. |
| 결과 요약 | 서버의 통화 단위 `summary`를 표시한다. 값이 없으면 마지막 발화의 `context_judgment.result.reason`을 표시한다. 근거도 없으면 기존 빈 상태 표시를 사용한다. |

종료 응답 최상위 `title` 또는 `summary`가 비어 있으면, 서버에 종료가 확인된 같은 `conversation_id`로 인증된 `POST /api/v1/conversations/summary`를 요청한다. 요약이 늦거나 실패해도 최종 점수와 먼저 저장한 기록은 유지한다. 성공하면 결과 화면과 해당 기기 기록을 갱신한다. 이미 삭제된 기록은 다시 추가하지 않으며, 동의 철회 시 진행 중인 요청을 취소한다.

실제 서버와 휴대폰에서의 통합 검토는 후속 작업이다. [앱·서버 계약](../server/document/APP_SERVER_CONTRACT.md#9-통화-종료-확정)
