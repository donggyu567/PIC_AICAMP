# 대화·출처 그룹 분할과 누출 검토 계획

현재 파일은 **분할 후보 manifest**입니다. 기존 v1 JSONL을 변경하거나 실제 평가 정답을 승인하지 않았고, 기존 v2 합성 자료를 TEST로 승격하지 않았습니다. 분할 seed는 `20261106`이며 학습 seed 42·43·44와 별개입니다.

## 확인한 자료 제약

복구한 68대화·1,460발화에는 source 44개, source_item 67개가 있으나 확정된 시나리오 가족 manifest는 없습니다. source_item의 `첫 녹음` 같은 값은 서로 다른 source에서 재사용되므로 source와 조합해 그룹 키로 씁니다. 출처는 가족을 대신하는 보수적 proxy이며 사람이 전개를 검토해야 합니다.

`app_installation` 양성 **6발화·5대화가 모두 source S009**에 있습니다. 같은 source를 유지하면 앱 설치 양성은 하나의 독립 그룹에만 있으므로 TRAIN·VALIDATION·TEST에 나누어 배치할 수 없습니다. 출처를 쪼개 수치를 맞추지 않았습니다.

80/10/10의 약 54/7/7, 70/15/15의 약 48/10/10은 목표 비율입니다. 분포를 맞추려고 연결 그룹을 깨지 않습니다. 엄격 정책의 실제 결과는 약 89.7/5.9/4.4%이며 일반적인 70~80% TRAIN 비율이 그 정책에서는 불가능합니다.

조건부 정책의 예외 제안은 **양쪽 현재 라벨이 정상이고 정규화 길이가 20자 미만인 공통 표현**에만 적용했습니다. 20자는 확인된 진실이나 최적 임계값이 아니라 사전에 제안한 검토 기준입니다. 위험 발화, 동일 출처, 긴 문장, 전체 대화 유사성은 이 예외로 풀지 않습니다. 짧아도 시나리오 증거이면 예외를 거부하고 그룹을 합쳐 모든 후보와 설정을 다시 생성해야 합니다.

현재 128개의 교차 예외 edge는 [short_normal_exception_review.csv](short_normal_exception_review.csv)에 원문/정규화 표현·ID·양쪽 역할과 함께 남겼습니다. **이들은 미승인 예외이며 누출 없음으로 통과시킨 것이 아닙니다.** 기존 9개 의미적 검토 쌍과 마찬가지로 동일 시나리오가 확정됐다는 뜻도 아닙니다.

## 할당 규칙과 실제 분포

원자료 ID·출처·라벨의 계획용 통계만 사용합니다. seed로 tie-break 순서를 고정하고 가장 큰 그룹을 TRAIN에 둡니다. 가능한 경우 각 평가 후보에 양성 그룹 하나와 완전히 정상인 그룹 하나를 먼저 배치한 뒤 대화 수 목표의 부족분을 채웁니다. 모델 점수·loss·TEST 성능을 보고 분할을 선택하지 않습니다.

초기 초안에서 VALIDATION에 완전히 정상인 대화가 없어, 평가 정답을 동결하기 전에 위 정상 그룹 예약 규칙을 보완했습니다. 라벨·본문 변경이나 모델 성능 기반 선택은 없었습니다.

## 희귀 라벨과 신뢰성

- 앱 설치는 양성 그룹이 하나라 현재 출처 격리 조건에서 학습·독립 평가를 모두 충족할 수 없습니다. 합성 TEST를 자동 추가하거나 S009를 쪼개 해결하지 않습니다.
- TEST 비밀유지 양성도 0입니다. 두 유형의 recall/F1/AUC는 N/A로 표시하고 임의로 0이나 1을 대입하지 않습니다. 완전한 8종 macro F1은 추정 불가입니다.
- 개인정보 2개·위협 1개 양성으로는 숫자가 나와도 불확실성이 큽니다. 표본 수뿐 아니라 양성 대화·독립 그룹 수도 함께 보고합니다.
- 동일 그룹 제약을 지킨 그룹 교차검증을 보조 계획으로 고려할 수 있지만, 앱 설치 그룹을 뺀 fold에서는 해당 유형의 학습 양성이 0이므로 근본적 신뢰성 문제는 해결되지 않습니다. 데이터가 부족한 사실을 숨기기 위해 CV 평균으로 합치지 않습니다.
- 최종적으로 8종을 평가하려면 사람이 검증한 별도 독립 출처의 자료가 필요합니다. 이번 작업에서는 그런 자료를 만들거나 승인하지 않았습니다.

## 동결과 TEST 보호

1. 기존 132발화·9쌍·v1 유사 문장 1쌍, 조건부 분할 예외 128건, 출처별 의미적 가족을 사람이 검토합니다.
2. 후보 holdout 20대화·517발화의 라벨과 마스킹·정상 문맥을 독립적으로 검수합니다. 과거의 `approved_for_training`은 평가 정답 검증을 뜻하지 않습니다.
3. 승인된 예외·가족·정답이 확정된 뒤 manifest와 파일 SHA를 새 protocol version으로 동결합니다. 지금의 DRAFT를 그 상태로 간주하지 않습니다.
4. TEST membership와 gold는 최종 평가 담당 흐름에 봉인합니다. 학습·B 설정 선택·조기종료·임계값 선택에는 넣지 않습니다. 현재 TEST 후보의 DataLoader 검사는 형식 확인이며 모델 예측을 생성하지 않았습니다.
5. A/B/C와 세 시드의 체크포인트·고정 threshold·선택 규칙을 먼저 확정한 뒤 같은 TEST를 한 번의 최종 평가 작업에서 사용합니다. 최종 FP/FN을 보고 개선한다면 다음 반복은 새 독립 TEST가 필요합니다.

새 모델들은 공개 기반 encoder에서 시작하고 이 분할의 TRAIN만 보도록 할 예정이므로, 동결·검수 후 holdout을 새 모델에 대한 독립 평가 후보로 사용할 수 있습니다. 과거 68개를 모두 본 v1 모델의 독립 평가 분할을 복원한 것은 아닙니다.

## 합성 자료 경계

기존 v2 TRAIN 후보 208개는 최종 승인 0개입니다. 조건부 v1 holdout 517발화와 문자열 107,536쌍을 추가 비교한 결과 정규화·완전·0.80 이상 후보는 0이지만 의미적 가족 독립성은 미검증입니다. 이전 유사도 0.814815인 v1 `P0005-5`는 현재 후보에서 TRAIN에 배치됐습니다. 이 일반 신청 부인 문장 유사성을 확정된 데이터 재사용으로 처리하지 않았고 검토는 유지합니다.

실험 C에는 사람 승인 및 학습 사용 결정이 확인된 합성 TRAIN만 추가합니다. v1 holdout과 의미적으로 같은 가족으로 판정되면 먼저 공통 평가 집합을 보호하는 처리 방침을 정하고 수정/재분할은 별도 검수된 버전으로 해야 합니다. TEST를 보고 C 데이터를 유리하게 바꾸지 않습니다. 기존 합성 VALIDATION 24대화·192발화는 검수 후에도 보조 진단용으로 구분하며 공통 최종 TEST로 자동 승격하지 않습니다.
