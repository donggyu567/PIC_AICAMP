일반 학습 게이트는 현재 데이터를 일부만 조용히 선택하지 않고 전체 208개를 차단합니다. 검수표는 발화별 원문·라벨·근거가 현재 정본과 같은지, 양쪽 검수 결과와 실제 시각·최종 합의·미해결 수정안이 없는지 확인합니다. 별도 학습 사용 결정은 데이터 fingerprint에 결부되어야 합니다. 이번 작업에서 그러한 결정을 작성하거나 승인하지 않았습니다.

사전 검증 게이트는 승인 필터를 무력화하는 학습 옵션이 아닙니다. `training_allowed=false`인 분리된 결과를 반환하고, 현재 감사 도구에는 실제 학습 함수나 체크포인트 출력 기능이 없습니다. 기존 PyTorch Dataset/loader 자체는 split이나 사람 승인을 해석하지 않으므로, 추후 실제 실행 코드가 이 반환 타입을 버리고 임의 입력을 전달하면 경계가 사라집니다. 최종 학습 진입점 결합은 아직 필요한 작업으로 명시합니다.

모델 입력은 과거 최대 5발화만 보지만 일부 사칭 라벨은 전체 합성 시나리오의 속성에 기대고 있습니다. 미래 발화나 시나리오 요약을 모델 입력에 추가해 해결하면 실시간 입력 계약이 바뀌므로, 이번에는 해당 사례를 사람 검토 대상으로만 남겼습니다. 라벨 정의와 실제 예측 시점의 가시성을 먼저 합의해야 합니다.
