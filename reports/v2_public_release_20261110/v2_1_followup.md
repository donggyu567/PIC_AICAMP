# v2.1 후속 개선 제안 — 이번 버전은 보존

1. 정보탐색의 별도 시나리오·표현·정상 질문 hard negative와 독립적인 사람 라벨 검수를 확보한다.
2. 개인정보 요구의 높은 seed 민감성과 precision/recall 불균형을 새 TRAIN/VALIDATION에서 진단한다. 현 TEST 결과에 맞춰 threshold를 변경하지 않는다.
3. 실제 정상 금융·설치·본인확인·개인정보 보호 통화와 ASR 오류를 포함한 별도 승인 평가 자료를 만든다.
4. v2.1은 새 protocol·split·가족 registry·새 최종 TEST를 등록한 뒤 실험한다. 현재 v2 원본·선택·체크포인트·평가 결과는 변경하지 않는다.
5. 별도 배포 승인 후 서버 어댑터·동시성·latency·실패 응답·통화 상태 통합을 검증한다. 이번 요청에서 v2.1 학습이나 운영 배포를 수행하지 않았다.
