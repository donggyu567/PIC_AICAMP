# VALIDATION 독립 2인 검수

`human_review.csv`는 기존 TRAIN 검수표와 같은 열 순서의 UTF-8 BOM CSV입니다. 총 192행이며 김해린·임정윤의 검수 결과와 최종 합의 결과는 모두 `미승인`, `학습_반영`은 모두 `미반영`으로 시작합니다. 승인 및 검수 시각을 자동 입력하지 않습니다.

각자 자신의 `검수_결과_이름`, `수정_의견_이름`, `검수_일시_이름` 열에 실제 검토 결과를 남깁니다. 결과 값은 기존 표와 같은 `미승인`, `승인`, `수정요청`, `보류`를 사용합니다. 수정요청·보류에는 이유를 적고, 검수 시각은 실제로 검수한 시각을 기재합니다. 다른 검수자의 결과를 대신 입력하지 마세요.

대화 요약·원문·원래 라벨·라벨 근거 등 출처 열은 보존하고 변경안은 수정 의견 또는 합의 수정안에 남깁니다. 앞뒤 발화가 필요한 경우 같은 대화의 행들을 순서대로 읽습니다. 특히 [시나리오 설계표](../../../reports/v2_validation/scenario_design.md)와 TRAIN 정본을 함께 대조해 단어만 바꾼 전개가 없는지 확인합니다.

두 사람 모두 실제 승인한 뒤 합의한 경우에만 최종 합의 및 실제 시각을 입력합니다. 이 작업에서 최종 승인이나 데이터 수정 적용을 수행하지 않았습니다. 검수가 끝나더라도 이 자료의 split은 VALIDATION이며 TRAIN에 반영하지 않습니다.

생성기와 자동 검증기는 최초 미승인 상태 확인용입니다. 사람이 편집한 CSV와 내용이 다르면 생성기는 덮어쓰기를 거부하고 검증기는 불일치를 보고합니다. 기존 검수 결과를 초기화하지 마세요.
