# 신규 TRAIN 8대화 사람 검수

`human_review_new8.csv`는 0017~0024의 모든 72발화를 담습니다. 기존 TRAIN과 동일한 열 순서의 UTF-8 BOM CSV입니다. 김해린·임정윤의 결과와 최종 합의는 전부 `미승인`, 학습 반영은 `미반영`, 검수 시각은 공란으로 시작합니다. 기존 16대화의 검수표는 이 파일에 복사하거나 수정하지 않았습니다.

각자 자신의 검수 결과·수정 의견·실제 검수 일시를 작성합니다. 허용 결과는 기존과 같은 `미승인`, `승인`, `수정요청`, `보류`입니다. 수정요청·보류에는 이유를 남기고 다른 사람의 결과를 대신 입력하지 마세요. 두 사람 모두 실제 검수·승인하고 합의한 경우에만 최종 합의를 기록합니다.

출처 열인 원문·요약·원래 라벨·근거·ID는 보존합니다. 수정이 필요하면 의견과 합의 수정안에 변경 내용과 사유를 남기고 임의로 행을 삭제하지 않습니다. 전후 맥락은 같은 대화의 행을 순서대로 읽어 확인합니다. [시나리오 사후 비교표](../../../reports/v2_train_expansion/scenario_independence_review.md)의 공유 기제와 다른 전개도 함께 검토합니다.

우선 검토는 0017-7, 0019-6, 0020-9의 멀티라벨, 0018의 떠보기·정확정보 구분, 0020의 기존 선입금형 사기와의 의미적 근접성, 정상 4대화의 본인 확인·안전 통제·정보 보호 문맥입니다.

검수가 진행된 CSV는 생성기로 초기화하지 마세요. 현재 통합 후보는 학습 허용 상태가 아니며 검수표 편집만으로 자동 학습·라벨 반영은 이루어지지 않습니다.
