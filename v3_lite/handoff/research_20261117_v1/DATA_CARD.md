# Research synthetic v3 data

기존 TRAIN80대화/656발화와 신규 TRAIN24대화/192발화를 합쳐104대화/848발화다. 위험209발화, 정상 대화38개다. 정보탐색은 양성39/음성809, 개인정보는 양성42/음성806이다. 샘플링 확대나 가중치 변경 없이 전체를 셔플해 한 번 학습했다.

새 VALIDATION32대화/256발화/32가족은 위험60발화·정상12대화이며, 두 목표 유형은 각각18양성/6가족이다. 일부 나머지 유형은1가족/3양성뿐이다. 기존 VALIDATION32/256은 회귀 진단에만 사용하고 TRAIN에 넣지 않았다.

신규56대화의 가족별 분할 계획을 발화 작성 전에 만들었다. Codex 세션이 각 대화를 개별 작성했고 코드는 직렬화/검사를 했다. 정확한 backend model ID는 주장하지 않는다. 실제 기관 연락처/계좌/인증값/작동 URL과 제3자 통화 전사는 사용하지 않았다. 필요한 식별정보는 기존 마스킹 토큰으로 표현했다.

연구 허용 근거는 사용자의 명시적 자체 합성 생성·내부 학습 요청과 기존 v2 내부 합성 정책이다. 정식 독립2인 검수 게이트와 분리된 research_synthetic_v3 경로만 사용했다. human_reviewed=false/label_status=provisional이며 사람 검수 기록을 생성하지 않았다. 별도 AI 재독·자동 검사 PASS는 사람 승인이 아니다.

정규화한 신규 TRAIN192문장과 VALIDATION256문장은 각각 모두 고유하고 분할 간 동일 문장은0개였다. 가족/대화/발화 복합ID, canonical 라벨, 현재 위험 여부, 과거5턴, 마스킹, provenance를 검사하고 기존 v2 TRAIN/VALIDATION과 대화 유사도0.8 이상 중복을 차단했다. 의미적 독립성은 자동 검사로 입증되지 않는다. v2 TEST 원문/암호문/개별 예측/정답/해제 원본은 읽지 않았다.

자료는 학습 전에 해시와 설정을 동결했으며 점수가 불리하다는 이유로 고치지 않았다. 미검수 원문·개별 예측·사용자 승인 원본은 Git/공개 패키지에서 제외한다. 전체 유형 통계/해시는 DATA_STATISTICS.json과 TRAINING_HISTORY.json을 참조한다. 새 독립 TEST, 실통화/STT, 사람 라벨 검수는 향후 과제다.
